AI engineering evidence

Stateful orchestration, model selection by task, tool calling, MLflow packaging, serving deployment, OAuth integration, and automated checks across the app-to-model request path.

Controls and scope

SELECT-only SQL with catalog/schema checks; bounded execution; API allowlist, input-size and path checks; no arbitrary generated Python execution. DAB configuration and GitHub Actions support repeatable deployment and validation.

Portfolio deployment, not a production-readiness claim. ETL output is temporary. PDF retrieval is lexical, not Vector Search; scanned documents require OCR. Four smoke checks establish tested paths, not universal answer accuracy.
